# Bilal Ahmed — Developer Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## About
Bilal Ahmed is a Computer Science student at Muhammad Ali Jinnah University (MAJU), Karachi, exploring web development, Python, SQL, data engineering and AI.

## Run locally
1. Download or extract this project folder.
2. Open `index.html` in a browser.
3. For a better development workflow, open the folder in VS Code and use a local server extension if installed.

## Before publishing
- Confirm education and semester details.
- Replace the email placeholder with a professional email.
- Add the correct LinkedIn profile URL.
- Verify project completion and add real source/demo links.
- Add an updated CV PDF only after reviewing it for personal information you want public.
- Remove any details you do not want publicly visible.

## Publish with GitHub Pages
1. Create a repository named `bilal-portfolio` on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment to finish. GitHub will show the published site URL in Pages settings.

This is a static website; it does not include a backend or a working contact form.
